# BH1750 独立总线改线版 · 2026-10-27

本目录的飞控源码及重新构建的基础、单光源、A/B HEX 对应以下接线。无线协议保持 J31，原配套遥控程序可继续使用；遥控源码未修改。

| 模块信号 | 主控板接口 |
| --- | --- |
| GY-302 VCC | UART1 插座 3V3 |
| GY-302 GND | UART1 插座 GND |
| GY-302 SCL | UART1 插座 TX1，即 PA9 |
| GY-302 SDA | UART1 插座 RX1，即 PA10 |
| GY-302 ADDR | GND，7 位地址 0x23 |
| LC08 SCL / SDA | 原 I2C 插座 SCL/PB6、SDA/PB7 |
| LC08 VCC / GND | 原 3V3 / GND |

PA9/PA10 是软件 I²C，不是通过串口通信；不得再调用 `USART1_Config()`、连接 USB-TTL 发送器或将 GY-302 信号同时并回 PB6/PB7。GY-302 自带上拉保留。两路信号分开，3.3 V 与地共用；电源短路不能靠此改线消除。

飞控入口为 `flight/mini.uvprojx`，基础 HEX 为 `firmware/basic/flight_basic.hex`。新文件 `HARDWARE/j_bh_i2c.c/.h` 已加入 Keil 工程；`j_bh1750.c` 改为使用新总线，并在 `JBH_Init()` 内初始化开漏 GPIO。原 PB6/PB7 驱动、800 mm 目标、检光判据及控制协议保持原设定。Keil 链接器关闭自动内存布局，明确使用 `j_memory.sct`，以保留原 IMU 标定页。

无桨、保持上锁进行台架核对：

1. 断电确认线序与 ADDR 接地，上电检查 3.3 V 供电正常；事务间隙且引脚释放时 PA9/PA10 应为高电平。若持续低电平，检查接线、供电及上拉。
2. 更新基础飞控固件，关闭测试光源。检查 `j_sensor.value.light_ok=1`、`light_id` 约每 204 ms 增加、`lux` 随光照变化；观察 `j_bh_i2c_errors` 是否持续增长。
3. 同时检查 `j_sensor.value.range_ok`、`imu_ok` 以及激光高度；它们仍由 PB6/PB7 提供。
4. 断电后断开 GY-302 的信号线，再上电，确认光照读数无效，而激光/IMU 仍可正常更新。恢复接线后重新上电检查重试和样本恢复。
5. 使用逻辑分析仪时，PA9/PA10 应看到 7 位 0x23（写地址字节 0x46、读地址字节 0x47），命令顺序 0x01、0x07、0x20，等待约 185 ms 后读取两字节，第二字节以 NACK 结束。

软件验证日志见 `verification/native/bh_i2c/results.log` 和 `verification/software_results.json`，构建与容量结果见 `verification/构建与测试汇总.md`。软件测试没有替代实物电气、调度耗时和飞行验证。本次不连接硬件、不烧录或运行电机。
