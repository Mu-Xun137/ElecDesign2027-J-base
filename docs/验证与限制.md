# 验证范围与交付依据

2026-10-29本另存版 `J31-20261029-NEAR-LIFTOFF` 增加用户选择的方案A：没有高度反馈的受限近地起飞，可靠测距后交给800mm闭环。保留LC08毫米输入和TIM1初始化修复。前一单位修复版已经由用户烧录并经拆桨只读静态复测确认；当前近地版尚未烧录或试飞，详见 [近地阶段](近地起飞阶段与验证_20261029.md)。

本次构建和本机测试由实际源文件产生，没有使用原基线/参考目录旧HEX或旧编译对象充当成果。定位阶段连接J-Link，只读取拆桨上锁状态下原版及用户烧录的RANGE-MM，确认单位修复和近地无效输出；助手没有烧录、改写电机指令、运行电机或试飞。后续编码期间无需给飞机通电。静态实机证据与本机回归分别记录，不混为当前近地固件的实飞通过。

四个构建结果和资源表由最终核验生成在 `verification/构建与测试汇总.md`：基础飞控、基础遥控、干净基础副本应用增量后的单光源和 A/B 飞控。MCU 仍为 STM32F103C8，真实 64 KB Flash、20 KB RAM；工具为 ARMCC 5.06 update 7 build 960，没有迁移 HAL/RTOS/MCU。飞控为新增中断路径预留 4096 字节栈，RAM 表按最高运行时地址计算，包含解压后的 RW 间隙与保留栈；尚未实测栈高水位。

原 IMU 标定页位于 `0x08007C00～0x08007FFF`。`flight/j_memory.sct` 使用两段真实 Flash 装载区避开该页；HEX 检查确认没有写入记录落入标定页。**这不保证烧录器的全片擦除保留旧标定**：用户烧录前需备份标定，按实际擦除策略处理，必要时重新校准。交付以稀疏 HEX 为准，没有给飞控生成会填充标定页的平铺 BIN。

原库仍有已知编译告警：飞控 `CONFIG/USB_HID.c` 两处、`HAL/ANO_DT.c` 一处枚举混用；遥控原 `StartUp/system_stm32f10x.c` 一处未引用静态时钟函数。新 J 模块不引入告警；没有通过关掉全部警告或改容量规避检查。

软件测试直接编译交付 C 模块。`test_core.c` 使用注入时钟/测量运行真实控制状态机；`test_protocol.c` 使用真实编解码、接收器、物理按键去抖和蜂鸣仲裁；`test_hardware.c` 编译真实平台适配、MPU/LC08/BH1750 驱动、姿态 PID、混控、SysTick 和 TIM1 代码，仅以寄存器、I²C、无线、姿态估计/加速度滤波桩替代硬件依赖。导航用实际升级 C 文件执行，坐标/光照采用可复现的理想运动和高斯/平坦/梯度/闪变光场；这些模型是测试输入，不冒充飞行动力学或灯具实测。

改线版新增 `test_bh_i2c.c`，直接运行实际 PA9/PA10 驱动，以开漏从机桩核对 GPIOA 9/10 开漏及初始释放、0x46/0x47 地址、命令与两字节读取、ACK/末字节 NACK、STOP、NACK 后重试、SCL/SDA 卡低的有界退出和有限时钟拉伸。平台桩另验证光感通信失效时激光和 IMU 仍有效。电气电平、上升时间、实际总线频率和中断耗时仍需实物测量。

TinyCC 0.9.27 Win64 的复杂浮点实参曾在最小复现中把理论 0 的限幅输入算错。实际 C 运算改为先存中间结果再调用限幅，并以高度平衡/接管回归锁定行为；调查材料隔离在 `verification/toolchain_probe/`。单精度 C99 数学函数在本机测试中用 CRT 双精度函数包装，固件使用 ARM 自身单精度库。最终测试的源码、头文件和编译宏哈希随结果保存。没有把 TinyCC 运行结果称为 MCU 固件运行或实机飞行通过。

本版全部107个软件用例、102082次断言通过。近地用例覆盖准入、一次性起转资格、限速/限幅、C2/失联/IMU/通信/姿态/控制超时、短小/陈旧高度拒绝、连续测距接管与输出连续、C4无高度接管/取消、时间回绕和重复调度。真实驱动/PWM桩同时覆盖近地起转和2秒停机，以及无线C2即时清输出。

另用Unicorn执行交付固件实际ARM代码：三种飞控各6项近地状态机回放（共18）、各6项测距及通信时间戳检查（共18）、各4项TIM1脏栈/寄存器检查（共12），合计48项通过。ARM回放时间步6ms，覆盖实际指令行为，未模拟中断执行耗时、无线电、电气噪声或飞行动力学。当前HEX/AXF哈希与这些报告绑定。

## 与 J 题的已接受差异

题面只按提取的 J 题核对，原文保存在 `verification/J题_原文提取.txt`。本方案的蜂鸣器在遥控 PA12，并非机载蜂鸣器；C2 是无线急停，并非题面独立硬件急停。基础版人工水平对准+照度代理不等于自主导航或几何正上方证明；升级是需实测标定的实验导航。A/B 每点实际稳定 3 秒，满足发挥部分每点不少于 2 秒的时间要求，但尚未验证实际飞行与赛场评分指标。

这些差异没有被软件测试或编译通过消除。题面其他硬件、防护和比赛条件仍由用户按实际样机验收；本次没有替不存在的电压接线、气压计或硬件急停编写虚假的“已具备”状态。
