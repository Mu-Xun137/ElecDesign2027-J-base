# 操作与无桨验收

## 默认基础版操作

接线已更新为 [BH1750 独立总线](BH1750独立总线接线与验证.md)：GY-302 SCL→UART1/TX1/PA9、SDA→UART1/RX1/PA10，VCC→3V3、GND/ADDR→GND；LC08 保留原 I2C/PB6/PB7 接线。

1. 飞控和遥控分别使用 `firmware/basic/flight_basic.hex`、`remote_basic.hex`。两端必须配套；工程分别为 `flight/mini.uvprojx`、`remote/remote.uvprojx`。
2. 上锁时关闭测试光源，让向下 BH1750 获取至少 5 个有效环境样本，约需 1 秒。重换场地或灯光后，重新上锁采样；解锁后基线冻结。
3. 三轴杆回中，油门先低于 1150、再高于 1800 持续至少 60 ms、最后低于 1100，完成原低→高→低人工解锁。整个序列初设限时 10 秒。油门低于 1050 且偏航低于 1150 会急停，不能用该组合解锁。
4. 底杆按 C3：真实高度闭环爬升至 800 mm，目标变化初设 250 mm/s，公共推力变化受限。到 800±50 mm、垂速/光流/姿态持续稳定约 300 ms 后，启用本轮光源和高度告警。
5. 基础版用横滚/俯仰杆平移对准地面光源，回中后光流保持；偏航可操作。C3 普通悬停不受油门杆改变高度。
6. 检光达到连续 3 个新样本后，立即固定水平/偏航目标并平顺回到 800 mm；LED 全闪 3 秒，遥控连续鸣响 3 秒。稳定确认 300 ms 后，另连续稳定悬停 3 秒；失稳会重新计时，总强制窗口最多 10 秒。
7. 同一持续光照只触发一次。低于退出阈值连续 3 个新样本后，重新进入才可再次触发。任务完成后普通 800 mm 悬停，水平/偏航恢复；人工油门仍须 C4 对位。

## 按键和控制权

| 按键 | 行为 |
| --- | --- |
| C1 · PA15 | 人工模式进入当前位置定高/光流模式；地面可预选，仍须实际推杆启动电机。C3 普通悬停或搜索中取消任务转 C1。C1 再按进入油门对位，不能直接切人工。自动爬升和光源强制期忽略。 |
| C2 · PB11 | 最高优先级上锁并立即清四路 PWM。与其他键同时按仍有效；急停后须重新人工解锁。按住真实 C2 会持续阻止重新解锁。 |
| C3 · PC14 | 从其他正常模式开始新任务；C3 内重按不重置爬升、搜索、等待、进度或完成状态。任务结束须先正常离开 C3 再按，才开新任务。 |
| C4 · PC15 | 首按提出人工接管请求，自动继续保持。移动油门按声音提示实时对位；三轴回中、控制数据够新，持续匹配 200 ms 后接管。再按取消请求，继续自动；不强切、不设普通对位超时。 |

C1 的油门中立区为 1150～1750，进入/返回 C1 要先回该区，之后上推超过 1750 上升、下拉低于 1150 下降。地面预选 C1 不自动起转：先确认低杆，再上推超过 1100 才启动；从停转地面 C1 退出也经过零输出对位，不会凭模式切换起转。

C4 对位比较每个电机周期的实际限幅、取整公共推力，使用同一个原手动公式 `200 + 0.45×(通道−1000)`；默认通道上限约 1819，不能假定满杆为 2000。若自动推力超出手动范围，会持续提示无法匹配。对位期间油门不改变目标高度，底杆不累计人工低油门停机计时。人工接管后低于 1010 持续 900 ms 停转、持续 9 秒上锁，是集中配置的初始值。

光源强制期消费并丢弃 C1/C3/C4 和普通杆输入，不排队；原始急停组合、C2、传感器保护和失联保护始终保留。

## 灯效

| 状态 | 灯效 |
| --- | --- |
| 上锁待机 | 从左前开始，俯视顺时针，每 200 ms 一灯；重新进入锁定从左前重新起步。 |
| 解锁未起飞 | 两蓝、两红每 500 ms 交替。 |
| C3 自动爬升/调到 800 mm | 全灭；不以高度越界灯表示正常爬升。 |
| 普通到位，600～1000 mm 含边界 | 全灭。 |
| 已启用告警，低于 600 mm | 两红每 500 ms 翻转，首次越界先亮。 |
| 已启用告警，高于 1000 mm | 两蓝每 500 ms 翻转。 |
| 新光源确认 | 四灯每 100 ms 同步翻转，共 3 秒。 |
| 光源稳定确认到位 | 四灯全亮，确认离开后清除；全亮与稳定悬停 3 秒的“完成”标志不同。 |
| C4 后人工控制 | 高度告警仍保留，范围内按普通/到位显示。 |
| 传感器故障 | 清除本次到位灯锁存；仍健康的高度可按越界红/蓝指示，遥控报告故障。 |

优先级：上锁/安全状态统一管理；飞行中首次检出全闪 3 秒 > 高度红/蓝越界 > 到位全亮 > 普通状态。预设 LF=CH2/PA7/蓝、RF=CH1/PA6/蓝、RR=CH4/PB1/红、LR=CH3/PB0/红；均按低有效 PWM。实际布局尚未实物核验。

## 蜂鸣声型

| 事件 | 实际初始声型 |
| --- | --- |
| 新光源事件 | 连续 3000 ms；正常新事件收到后完整响 3 秒，重复状态包不重启。 |
| 高/低高度越界 | 同声：每秒一次 100 ms 短鸣，颜色区分高低。 |
| 需上推油门 | 90 ms 短 + 100 ms 间隔 + 250 ms 长，每 1000 ms 一组。 |
| 需下拉油门 | 250 ms 长 + 100 ms 间隔 + 90 ms 短，每 1000 ms 一组。 |
| 实际完成接管 | 两次 90 ms 短鸣，中隔 100 ms，仅一次。 |
| 传感器故障、推力不可匹配、反馈丢失、急停 | 每组四次 60 ms 短鸣，间隔 60 ms，每秒一组。 |
| 普通有效实体按键 | 30 ms 极短鸣。 |

优先级：急停/故障 > 光源 > 接管 > 高度 > 按键。故障接管窗口按完整 1 秒声组交替播放故障与方向提示；方向改变最迟在下一组生效。恢复连接/遥控重启时，已进行中的光源报警仅恢复剩余窗口，不重播旧接管成功。急停回包清掉旧报警/成功待播动作。

## 无桨台架检查

1. 全部拆桨，先核对工程和 HEX 清单，配套更新两端。本文步骤由用户执行；本次未访问实机。
2. 上锁，观察左前→右前→右后→左后顺序；用慢录像核对 200 ms 和颜色。错误时只改 `j_config.h` 的通道、颜色 mask、极性，重新编译。
3. 只在上锁无桨时用 Keil Watch 读 `j_sensor.value`：激光约 80 cm 应为 800 mm；0 值/遮挡或掉线要置无效。倾斜、质量差及数据陈旧不能视为稳定。带桨试验不要暂停 CPU。
4. 光源关闭，读 `j_flight.ambient_count=5`、`baseline_lux`；开启光源，确认 BH1750 `light_id` 约每 204 ms 才递增一次，而非每次 3 ms 调度递增。解锁后改变环境照度，基线不应跟着改变。
5. 人工解锁后底杆 C3，无桨会因真实高度不升而超时，这是正确的闭环行为。核对爬升灯全灭、再次 C3 不重启、C1 爬升期忽略。C2 应立即令 `TIM2->CCR1..4` 全 0；同时按 C1/C2、C3/C2、C4/C2 也要有效。
6. 台架以可控高度变化和杆位观察 C4 方向、200 ms 回中匹配及再按取消。不要把没有桨的固定高度台架当作推力/稳定性标定。
7. 分别断电后断开 BH1750、LC08、MPU 信号连接，再上电检查故障状态。BH1750 独立 PA9/PA10 故障应使光照无效，不应直接使激光/IMU 通信失效；PB6/PB7 共用总线异常仍应看到 IMU 保护停机，不能误报成仅激光等待。两路共用电源，电源短路仍可能影响整板。激光故障窗口由确认持续失效起计最多 10 秒，未接管会停机，飞机会下落。
8. 断遥控上行，最后合法新帧超过约 500 ms 应上锁；仅反馈丢失时遥控告警，不能据此宣称飞控已停机。遥控重启/首包不得凭 AUX 默认变化起飞或接管；实体 C2 经 20 ms 物理去抖确认后的真实按住，包含开机时确实按住，仍优先急停。

最后由用户在受控防护场地逐步验证推力、PID、80 cm 起飞、光源实际连续稳定 3 秒、强制窗口 10 秒、失联门限和导航尺度。没有完成这些试验前，本交付只具备构建及软件验证结论。
