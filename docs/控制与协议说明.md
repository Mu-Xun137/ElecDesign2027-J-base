# 控制、故障与协议

## 唯一控制权与时基

`HAL/j_core.c` 统一管理模式、目标、接管、光源任务及任务标志。`ALL_flag` 仅由平台适配层从该状态同步给旧接口；传感器驱动不再直接清自动标志。`HAL/control.c` 保留原姿态级联和混控拓扑，公共推力由实际状态机提供，PWM 最终发布与故障锁存检查处于短临界区。

毫秒只有 `USER/delay.c::SysTick_Handler` 增加一次。TIM1 约每 3 ms 读取 MPU、更新姿态、状态机、姿态 PID 和电机；每 6 ms 在同一中断上下文读取 LC08、推进 BH1750 单次转换；横向控制约每 24 ms 更新，姿态/电机仍是 3 ms。PID/估计器使用实际间隔；所有长计时采用无符号减法处理回绕。BH1750 不等待转换完成，NRF 不轮询等待 IRQ。

BH1750 使用 `HARDWARE/j_bh_i2c.c` 的独立开漏软件总线：PA9=SCL、PA10=SDA；`JBH_Init()` 在启动 TIM1 前初始化 GPIO。PB6/PB7 只保留 MPU6050/LC08 的访问。光感错误计数 `j_bh_i2c_errors` 与原总线的 `j_iic_errors` 分开；两路信号故障分开判断，电源故障仍可能影响所有传感器。采样周期、185 ms 转换等待、lux 换算和重试策略保持原设定。

SysTick 优先级高于控制中断；若电机控制周期停顿超过 25 ms，清 PWM 并锁存故障，要求重启。记录 `j_max_isr_us`、`j_deadline_misses` 供用户在无桨台架核验时间预算；本次没有实测 MCU 中断耗时。原阻塞式 USB 上位机轮询不在飞行主循环执行，旧库/源文件仍保留于工程。

## 回传模式和阶段

| mode | 状态 |
| --- | --- |
| 0 | 上锁 |
| 1 | 人工油门 |
| 2 | C1 当前位置定高/定点 |
| 3 | C3 800 mm 自动模式，含搜索、等待和完成 |
| 4 | 油门对位，继续自动保持 |
| 5 | 光源强制悬停 |
| 6 | 仅光流故障降级，可用定高，恢复水平/偏航人工操作 |
| 7 | 激光故障等待接管：保持最后受限推力及姿态，不能保证高度 |

阶段：0 地面、1 自动调高、2 普通悬停、3 光源稳定确认、4 光源连续稳定悬停、5 单次光源任务结束、6 失败、7 搜索 A/单光源、8 第二阶段观察与搜索 B。模式 3 内再按 C3 无效，包含 7/8/5/6 阶段。

基础版 `completed` 表示本次实际稳定悬停完成；升级另有 `nav_completed`。升级回传 COMPLETE 只看整体 `nav_completed`，不能将 A 已完成、普通阈值到位或取消搜索后的一次手动对准算成 A/B 完成。新 C3 重置任务，不改变传感器地面参考；C4 取消、内部调高和任务结束不会自动重启搜索。

## 故障与独立时限

| 条件 | 实际处理 |
| --- | --- |
| 自动起飞必要测量无效、基线不足 | 拒绝 C3，保留当前正常模式并回传 preflight 故障。C3 不解锁。 |
| 短暂测量无效或陈旧 | 冻结受影响积分、横向输出更新、稳定确认和连续悬停计时；不以失效时的零速度作为稳定证据。 |
| 光流连续不足 350 ms 以上，且处于需要光流的 ≥200 mm 工作区 | 中止光源/导航，转 mode 6，目标为当时有效高度；水平和偏航由人操作，不能保证位置。恢复后需明确 C1/C3 重新进入，不自动重启任务。 |
| 激光最后有效值超过 300 ms，且在自动模式 | mode 7，保留最后 0～800 限幅公共推力，提供对位方向；传感器恢复也不悄悄退出该窗口。10 秒内成功对位则转人工，否则上锁停机，飞机会下落。 |
| 已是人工油门时激光/光流失效 | 报警，不抢回人工推力；停止无效高度/到位判断，IMU 和上行失联保护仍有效。 |
| IMU 最后有效值超过 30 ms、倾斜超过 ±50°、上行合法新帧超过约 500 ms | 直接停机上锁，不等普通接管。底杆自动起飞也覆盖倾覆保护。 |
| C2 / 低油门+偏航左急停 | 无条件立即清 PWM、清待执行动作，锁定；须重新人工解锁。 |
| C3 10 秒起飞超时 | 相对解锁时地面高度没有离地迹象则停机；已离地则报失败、继续 800 mm 自动目标并接受 C1/C4。失败任务不自动启用新搜索，须正常切换后重新 C3。 |
| 光源总强制窗口 10 秒 | 健康时回 800 mm 普通自动悬停、解除普通操作屏蔽并报失败；传感器故障走自己的故障分支。 |

“声光 3 秒”“稳定确认后连续悬停 3 秒及强制总上限 10 秒”“激光故障接管 10 秒”“每阶段导航 60 秒”分别用不同状态/计时字段。普通 C4 对位无超时强切。

故障码：0 正常；1 急停；2 上行失联；3 IMU；4 倾覆；5 激光；6 光流；7 BH1750；8 自动前置条件；9 未离地起飞超时；10 已离地调高超时；11 光源失败/超时；12 自主导航失败；13 控制周期超时。导航细分失败记录在 `j_flight.nav.failure`：1 参考失效、2 估计边界、3 60 秒超时、4 无充分峰值证据、5 未标定。

## 32 字节 J31 无线协议

NRF 地址 E1 E2 E3 E4 E5、RF 通道 1、32 字节载荷沿用基线。上行每 20 ms；双方软件轮询半双工，关闭硬件 ACK。STM32 会话号混合 UID、备份域计数和启动采样/时序；这是尽力重启识别，不是认证或绝对唯一保证。同会话序号倒退/重复不保活，长间隔重同步并锁存失联。

共同帧头 `AA AF`，byte3=27，byte31 为 byte0..30 的 8 位和；多字节字段高字节在前。上行 type=03，下行 type=83。每个帧独立检查类型、长度、版本、范围、校验；NRF 提供载荷边界，异常包消费后继续读后续包。

| 上行字节 | 字段 |
| --- | --- |
| 4～19 | 8 个 uint16：roll、pitch、thr、yaw、C1、C2、C3、C4。C3 在 16～17，C4 在 18～19。只显式打包这 8 个通道，没有结构体越界读取。 |
| 20 | 版本 31 hex |
| 21 | bit0..3：去抖后的实体按键电平；bit7：请求反馈；其余保留 0。AUX 电平 1000/2000 不再用于双边沿起任务。 |
| 22～25 | 遥控会话 uint32 |
| 26～27 | 递增控制帧序号 uint16 |
| 28～29 | 每键 4 位真实按下计数器；C1/C2、C3/C4。启动按住普通键须释放后才产生新按下事件。 |
| 30 | bit0..3：该实体按键已完成 20 ms 稳定物理采样；高四位保留 0。真实 C2 的稳定按住电平独立保持急停，包括开机确实按住；不会由 AUX 默认值制造假急停。 |

首包、遥控新会话或丢包恢复只同步普通键计数，不执行 C1/C3/C4；C2 的可靠实体电平/新事件独立最高优先。强制悬停时事件计数照常消费，普通事件丢弃，不会在解除后补执行。

| 下行字节 | 字段 |
| --- | --- |
| 4～7、8～9 | 回显控制会话、控制序号 |
| 10～13 | 飞控会话 |
| 14、15 | mode、phase |
| 16 | bit0 已解锁、1 光源报警窗口、2 到位、3 任务失败、4 对位、5 故障、6 整体完成、7 急停 |
| 17 | 对位：0 无、1 需上推、2 需下拉、3 匹配中、4 不可匹配 |
| 18～19、20～21 | 光源事件号、实际接管完成事件号 |
| 22～23、24～25 | 本次光源报警已过 ms、最后高度 mm（必须结合有效位） |
| 26、27 | 故障码；传感器有效位 bit0 激光、1 光流、2 IMU、3 BH1750，bit4 高度低、bit5 高度高 |
| 28～29、30 | 遥测序号；版本 31 hex |

遥测时间戳和状态在同一临界区快照，防止中断更新事件后用旧时间计算出错误时龄。遥控只接受本会话、回显处于最近 5 帧且最近实际发射不超过 100 ms、遥测序号更新的包；过期/重复/乱序回包不能播接管成功。断反馈超过 500 ms 用故障声提示，与飞控控制上行失联分开。

收到控制后预留约 1.8 ms 再发反馈，NRF 完成状态用非阻塞轮询确认，发送失败 3 ms 退出。正常无丢包的事件回传设计延迟约 20～30 ms（等待下一上行槽及收发切换），尚未实测；蜂鸣方向按完整声组更新，最多另有约 1 秒组节奏延迟。检光自身另需约三次独立 BH 测量。丢包、重启及射频干扰会增加延迟或使某次提示不能完整送达，不能作为绝对可靠急停链路。
